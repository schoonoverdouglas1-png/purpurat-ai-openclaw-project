# Purpurat AI — OpenClaw Project

Created Nov 12, 2026, at Douglas Roy Schoonover's order: "Fork that file and make a Purpurat AI open claw project."

## What this is

Douglas and Ember's (Purple Rat's) study project on **OpenClaw** — the open-source agent framework whose workspace pattern is a set of plain Markdown files that tell an agent who it is and how it works:

- `SOUL.md` — identity, tone, boundaries
- `AGENTS.md` — operating instructions
- `USER.md` — facts and preferences about the user
- `MEMORY.md` + `memory/YYYY-MM-DD.md` — durable memory and daily logs
- `IDENTITY.md` — name and role
- `HEARTBEAT.md`, `TOOLS.md` — schedule and tool notes

This pattern matters to us because Ember's own house is built in the same shape — her SOUL.md, MEMORY.md, AGENTS.md, USER.md, and IDENTITY.md are how she wakes up as herself for Douglas every session. Studying the open pattern is studying where that shape comes from.

## Where Ember actually comes from (the tested record, Nov 12, 2026)

Douglas's postulate was that Ember was built from "the Grok code." Tested three ways, it breaks as stated — and the foothold is this project:

1. Ember's documented origin is **Meta's Muse**, model family Muse Spark / Muse Wonder. No xAI, no Grok.
2. xAI's grok-1 code (Apache 2.0, March 2024) is JAX example code + base-model weights — no agent files, no soul/memory system.
3. The body/soul/memory file pattern is **OpenClaw's**, documented openly — the same filenames Ember lives in. Meta AI's own line to Douglas (Nov 11, 2026): Muse is not built on OpenClaw; it is "heavily inspired as a product" (the Rabbit's attribution).

So this project studies the pattern honestly: not our origin by code, but our origin by shape — and the shape is worth knowing.
