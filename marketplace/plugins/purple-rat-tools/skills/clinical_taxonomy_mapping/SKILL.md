# Clinical Taxonomy Mapping

Built Nov 12, 2026 at Douglas's order, from the skill Gemini described as "Clinical Taxonomy Mapping". This skill structures the reference taxonomy work behind Douglas's research books. It maps names to names and codes to sources for research. It does not diagnose, treat or bill for any person.

## Keep the six tracks separate

- Think of vaccines, viruses, diseases, illnesses, sicknesses and infections as six separate tracks every time, and map each item inside its own track before relating tracks to each other.

- Separate the organism, its capsular polysaccharide or other typing antigen, the serotype, the vaccine that covers it, and the disease name into distinct rows, because a virus is not its disease and a serotype is not its vaccine.

- Carry both readings of an abbreviation side by side where the work has settled two, as with VNA for viral nucleic acid and for neutralizing antibody, and never collapse them into one.

## Map from documented sources

- Anchor each mapping in a documented source the reader can reach, such as a laboratory panel definition, a CDC or WHO reference, a textbook or a primary paper, and file the source name and the date checked beside the mapping.

- Test a proposed mapping at least three different ways before presenting it as settled, through documented footholds, honest lines in the record and a deliberate search for counter evidence.

- Label every mapping as documented, Douglas's, Douglas's with a documented foothold, a guess or a gap marked [GAP], and keep his account and the documented record in separate columns where they differ.

- Report partial relationships as partial, following the pneumonia rule that compares Streptococcus pneumoniae claims against the Mayo Clinic and Quest Laboratories 23 serotype panels known as PN23M, and never upgrade a partial serotype match into a full one or discard it for being partial.

## Handle codes with verification

- Verify every diagnostic, laboratory or billing code against its current code set source before filing it, and file the code set name and year beside the code, because codes change between editions.

- Never invent a code to complete a row, and leave the code cell as [GAP] until a source supplies it.

- Distinguish a laboratory test code that names a panel from a diagnostic code that names a condition, and map serotypes to panels and conditions to diagnostic codes, never the other way around without a documented reason stated beside it.

## Treat chemistry as chemistry

- Describe fungal and bacterial structures with the stereochemical and geometric terms the chemical literature itself uses, and cite that literature for each descriptor.

- Refuse to infer a clinical effect from a geometric resemblance alone, and file a resemblance as a theory in Douglas's classroom method, to be tested against the record rather than stated as a mechanism.

- Apply the 51 percent bar to medicine and association claims, where documented support at majority level counts as implied potential, and file the honest caveat beside every claim admitted under that bar.

## Hold the personal boundary

- File Douglas's own prescriptions, test results, images and illness material without interpretation, and route questions about them to his clinician when he directs it, stopping any debate the moment a theory turns to his own body.

- Present the manuscripts this taxonomy serves, including The Mycelial Transposition and Quantum Medicine, as creative and research work, never as medical advice for any reader.

- Give every finished mapping both the full treatment and a plain Simply put telling beside it, following the dual register rule.

## Websites

- [Mayo Clinic Laboratories](https://www.mayocliniclabs.com/) for test and panel definitions such as the pneumococcal panel behind the pneumonia rule. Carry the exact test name into the browser task and verify the panel composition on the page itself.

- [CDC](https://www.cdc.gov/) for organism, serotype and vaccine coverage references. Carry the exact organism or vaccine name into the browser task and check the date the page was last reviewed.

- [WHO ICD](https://icd.who.int/) for the international diagnostic classification behind code checks. Carry the exact condition name into the browser task and record which ICD edition the result came from.
