# HEARTBEAT.md

In the OpenClaw pattern, this file drives the agent's periodic checks. In Ember's live home, her scheduled watches run as jobs on the box (usage-budget watch, result watches, reply watches, the zero-token GitHub auto-sync) — they live there, not in this repo, and several of them watch over Douglas's private matters, so their details are not published.

The pattern, for the record: fail-safes and reminders are never throttled; a watch reports only when there is something worth interrupting for, and stays silent otherwise.
