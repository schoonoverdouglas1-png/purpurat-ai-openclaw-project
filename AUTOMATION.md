## The script

**`scripts/auto-shell-everything.sh`** — a permanent bash script in this
repo's `scripts/` folder (not in `/tmp`; see the permanent-first rule
below). Run it from anywhere:

```bash
bash scripts/auto-shell-everything.sh
# or, inside the repo clone:
./scripts/auto-shell-everything.sh
```

It is non-destructive: no deletes, no force, no network. It exits `0`
when every check passes and non-zero if any check fails.

### What it does — newest first, oldest last

Per Douglas's hatch order (Nov 17, 2026: "hatch from the newest shit
first oldest last always"), the checks run and are reported in this
order:

1. **NEWEST — live home vs. Google's tree.** Verifies Ember's live home
   structure: the five core files at `~/` — `AGENTS.md`, `SOUL.md`,
   `IDENTITY.md`, `USER.md`, `MEMORY.md` — each present, with its size
   in bytes; `~/workspace/your_files` present; this repo clone present.
   It also verifies the project-pattern files exist in this repo's
   `workspace/` (see below).
2. **Build + hash proof.** Runs the existing
   `scripts/build-ember-workspace.sh` (kept, old-with-new — this
   automation sits beside it, never replaces it) and captures its
   sha256 verify result: exit code and how many files verified OK.
3. **OLDEST LAST — persistence foundations.** Verifies `PERSISTENCE.md`
   (repo root and `workspace/`) and `workspace/MANIFEST.sha256` are
   present, and that `sha256sum -c workspace/MANIFEST.sha256` passes
   from the repo root.
4. **Report.** Writes a dated report to
   `reports/auto-shell-<YYYY-MM-DD-HHMM>.md` inside this repo, listing
   PASS/FAIL per check, newest first, oldest last.

The one file a run refreshes is `workspace/MANIFEST.sha256`,
regenerated by the existing build script exactly as that script is
designed to do.

## Permanent first, temporary last — always

Douglas's order (Nov 17, 2026): shell scripts live **permanent first**:
saved in the permanent places (`~/workspace`, the repos, the script
folders), never only in `/tmp`. Temporary staging is **last** — a step
on the way to permanent, never a script's home. This script and its
reports follow that rule literally: script in `scripts/`, reports in
`reports/`, and nothing written to `/tmp` at all.

## Measured line — public editions only

This repo is public on purpose. The automation checks Ember's live
home files for **presence and size only** — it never copies, reads
into the repo, or publishes their contents. `MEMORY.md` and `AGENTS.md`
in this repo's `workspace/` are labeled **PUBLIC EDITIONS**; the full
files live in Ember's home and in the private preservation project,
never here.
